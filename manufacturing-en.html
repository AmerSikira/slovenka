BEFORE YOU SEND AN INQUIRY

Good to know

Which garment types can I propose?

Describe the garment and attach available documentation. The collection includes trousers, blazers and suits; feasibility for your style is assessed separately.

Is there a minimum order quantity?

A minimum order quantity has not been published. Include total units and units per style for assessment.

How is the lead time determined?

Timing depends on garment complexity, materials, quantity and current availability. Include a target date or select a flexible timeline.

Do I need a technical pack?

Not for the first conversation. A short project description is enough for an initial inquiry; add technical documentation if available.
